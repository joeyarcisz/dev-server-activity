# Support

## Bugs

Use the [bug report form](https://github.com/joeyarcisz/dev-server-activity/issues/new?template=bug_report.yml) for reproducible defects. Include the app version, macOS version, Mac architecture, installation source, and exact steps.

Remove personal project paths, client names, credentials, and other sensitive information before posting.

## Questions and feature requests

Use the [feature request form](https://github.com/joeyarcisz/dev-server-activity/issues/new?template=feature_request.yml). Please explain the local development workflow that creates the need.

## Security

Do not report vulnerabilities in a public issue. Follow [Security](SECURITY.md).

## macOS verification problems

Official releases should be identified by Gatekeeper as `Notarized Developer ID`. If macOS says a downloaded copy is damaged or the developer cannot be verified, delete that copy and download it again from the official GitHub Release. Do not bypass the warning. Compare the ZIP against the published SHA-256 checksum before reporting the issue.
